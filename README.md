# SMS Listener

Учебный проект для работы с событиями и обработкой SMS на Android.

## О проекте

Проект создан для практики взаимодействия Android-приложения с системными событиями и обработки входящих сообщений.

## Основные темы

- получение системных событий;
- обработка входящих SMS;
- Android permissions;
- работа с жизненным циклом приложения.

## Стек

- Android
- Kotlin / Java
- Gradle

## Запуск

Откройте проект в Android Studio, синхронизируйте Gradle и запустите приложение на эмуляторе или устройстве с необходимыми разрешениями.
